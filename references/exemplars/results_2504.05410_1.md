Our experiments measure the practical impact of our methods on accuracy and runtime for 5 tasks in different domains. We use task-specific metrics rather than evaluating the sampler's internal behavior (e.g., how accurately it estimates ${blackZ}$), but see REF. We compare AWRS to strong baselines through consideration of two versions: {blackARS-LCD}, which performs simple LCD using \emph{unweighted} adaptive rejection sampling, and {blackAWRS-SMC}, which uses the weighted version within SMC.

We first compare the following \textit{uncorrected} methods in terms of both runtime and downstream task accuracy. Methods in this section yield ${blackM}=1$ unweighted samples: \begin{itemize} \item \textbf{Base language model ({blackBase LM}).} Sample sequences of tokens from the language model (without forcing any constraints), i.e., sample ${black\boldsymbol{x}}\sim{blackP_0}$. \item \textbf{Locally constrained decoding with token masking ({blackTM-LCD}).} The standard approach to constrained decoding. We mask the entire token vocabulary, re-normalize, and sample. \item \textbf{Locally constrained decoding with adaptive rejection sampling ({blackARS-LCD}).} A faster implementation of LCD: rather than masking the entire vocabulary, we draw a sample from the same LCD distribution using ARS. (We do not yet use an importance-weight correction, so we run only the first rejection loop.) \end{itemize}
