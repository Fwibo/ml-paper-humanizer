\textbf{Original Data Shapley definition faces computational \& conceptual limitation.} However, Data Shapley, i.e., the application of the Shapley value in data attribution, has been limited to very small-scale models. Existing methods [cite] to estimate the Shapley value require retraining the model numerous times using different subsets of data to evaluate the contribution of each data source, making them computationally infeasible for foundation models.

On the other hand, retraining-based methods suffer from a conceptual issue often overlooked in the literature: \textbf{they assess data contribution for a general learning algorithm rather than a particular model.} While one might interpret the former as an approximation of the latter, these two quantities can be quite different in practice, especially when the learning algorithm is randomized and sensitive to factors like random initialization and training data order. In many real-life scenarios, however, the primary interest lies in understanding data contribution to the specific model being trained and deployed.
