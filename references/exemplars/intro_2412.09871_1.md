We introduce the Byte Latent Transformer~(\textbf{BLT}), a tokenizer-free architecture that learns from raw byte data and, for the first time, matches the performance of tokenization-based models at scale, with significant improvements in efficiency and robustness (\SREF). Existing large language models (\mathrm{llm}s) are trained almost entirely end-to-end, except for tokenization---a heuristic pre-processing step that groups bytes into a static set of tokens. Such tokens bias how a string is compressed, leading to shortcomings such as domain/modality sensitivity~[cite], sensitivity to input noise~(\SREF), a lack of orthographic knowledge~[cite], and multilingual inequity~[cite].

Tokenization has previously been essential because directly training \mathrm{llm}s on bytes is prohibitively costly at scale due to long sequence lengths~[cite]. Prior works mitigate this by employing more efficient self-attention~[cite] or attention-free architectures~[cite]~(\SREF). However, this primarily helps train \textit{small models}. At scale, the computational cost of a Transformer is dominated by large feed-forward network layers that run on every byte, not the cost of the attention mechanism.
